# ES6 Promises

This project is part of the Holberton School backend curriculum, focusing on learning and implementing ES6 Promises, `async`/`await`, and error handling in JavaScript.

## Requirements

* Allowed editors: `vi`, `vim`, `emacs`, `Visual Studio Code`
* All files interpreted/compiled on **Ubuntu 20.04 LTS** using **Node.js (version 20.x.x)** and **npm (version 9.x.x)**
* All files must end with a new line
* All functions must be exported
