# ES6 Data Manipulation

This project is a collection of exercises focused on mastering ES6 features and data manipulation techniques in JavaScript, such as array methods (`map`, `filter`, `reduce`), typed arrays, and data structures like `Set`, `Map`, and `WeakMap`.

## Learning Objectives

By completing this project, you will be able to explain and implement:
* Array manipulation using `map`, `filter`, and `reduce`
* Typed Arrays
* The `Set`, `Map`, and `WeakMap` data structures

## Requirements

* Allowed editors: `vi`, `vim`, `emacs`, `Visual Studio Code`
* All files interpreted/compiled on Ubuntu 20.04 LTS using Node.js 20.x.x and npm 9.x.x
* All files must end with a new line
* All functions must be exported
* Code tested using Jest (`npm run test`)
* Code verified against ESLint (`npm run full-test`)
