# Node.js Basics

This repository contains tasks and projects for learning the basics of backend development with **Node.js**, **Express.js**, file system operations, process handling, and testing in JavaScript.

## Learning Objectives
* Run JavaScript using Node.js
* Use Node.js modules (`fs`, `http`, etc.)
* Read files using Node.js modules
* Access command line arguments and environment variables using `process`
* Create small HTTP servers using Node.js and Express.js
* Create advanced routes with Express.js
* Use ES6 with Node.js via Babel-node
* Use Nodemon for faster development

## Requirements
* Allowed editors: `vi`, `vim`, `emacs`, `Visual Studio Code`
* Interpreted/compiled on Ubuntu 20.04 LTS using Node.js (version `20.x.x`)
* All files must end with a new line
* All code must use the `.js` extension
* Code must pass Jest tests and ESLint checks (`npm run full-test`)
* Functions/classes must be exported using: `module.exports = myFunction;`
